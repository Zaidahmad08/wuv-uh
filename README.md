# A little life, together

A static romantic keepsake for GitHub Pages. The site counts up from **12 February 2026 at 4:36 pm India Standard Time** and contains the complete 700-item bucket list in shared, editable wording.

## Add your doodles

Put your drawings in `assets/` with these exact names. Until a file is added, the page shows a quiet placeholder with its filename.

1. `first-date.jpg`
2. `where-we-met.jpg`
3. `little-traditions.jpg`
4. `silly-us.jpg`
5. `dream-trip.jpg`
6. `cozy-home.jpg`
7. `food-and-dates.jpg`
8. `growing-together.jpg`
9. `future-us.jpg`
10. `our-long-story.jpg`

Use JPG files with the names above. The art should be yours—there are no stock images in the project.

## Personalize the note

Edit the opening note, letter, and small captions in `index.html`. Edit the chapter names and introductions in `script.js`; edit the 700 individual ideas in `bucket-list.json`. Search the JSON for an idea number if you want to find a particular line quickly.

Each list item has a small menu where you can assign a time horizon, a star to save it, and a circle to mark it as a memory you made. This state is stored in the current browser only; it does not sync between devices.

## Publish with GitHub Pages

1. Copy the contents of this folder into the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select your publishing branch and the `/ (root)` folder, then save.
4. Add the resulting public URL to your Instagram bio when you’re ready. Anyone with that link can see the site and its images.

The site uses Google Fonts for its type pairing and falls back to system serif and sans-serif fonts if they cannot load. `bucket-list.json` must stay beside `index.html` and the scripts when hosted.
